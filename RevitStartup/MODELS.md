# Документация по моделям RevitStartup

Этот документ описывает все модели, классы и ключевые компоненты проекта RevitStartup. Он предназначен для ИИ-агентов, работающих с этим шаблоном, чтобы понимать архитектуру и назначение каждого компонента.

## Структура проекта

Проект использует следующую структуру папок:

- **Application** — верхнеуровневые команды, связь с Revit. Вызывает сервисы и окна
- **Resources** — внутренние ресурсы, иконки и т.д.

---

## Правила размещения файлов


### Application
Сюда кладутся классы, отвечающие за интеграцию с Revit:
- Классы, реализующие `IExternalApplication` (точка входа приложения)
- Классы для регистрации событий Revit


### Resources
Сюда кладутся внутренние ресурсы проекта:
- Иконки (.png, .ico, .svg)
- Изображения
- Встроенные ресурсы (Build Action: Embedded Resource)
- **Важно:** эти файлы никогда не копируются в выходную директорию и являются встроенными ресурсами
