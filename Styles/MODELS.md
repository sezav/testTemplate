# Документация по моделям Styles

Этот документ описывает все модели, классы и ключевые компоненты проекта Styles. Он предназначен для ИИ-агентов, работающих с этим шаблоном, чтобы понимать архитектуру и назначение каждого компонента.

## Структура проекта

Проект использует следующую структуру папок:

- **Styles** — ResourceDictionary Я
- **Resources** — внутренние ресурсы, иконки и т.д.

---

## Правила размещения файлов

- `Styles/` — стили, шаблоны, ресурсы XAML
- `Controls/` — пользовательские элементы управления
- `Resources/` - Сюда кладутся внутренние ресурсы проекта:
- Иконки (.png, .ico, .svg)
- Изображения
- Встроенные ресурсы (Build Action: Embedded Resource)
- **Важно:** эти файлы никогда не копируются в выходную директорию и являются встроенными ресурсами
