# Документация по моделям test_templateWPF

Этот документ описывает все модели, классы и ключевые компоненты проекта test_templateWPF. Он предназначен для ИИ-агентов, работающих с этим шаблоном, чтобы понимать архитектуру и назначение каждого компонента.

## Структура проекта

Проект использует следующую структуру папок:

- **UI** — все View и ViewModel, компоненты интерфейса (окна WPF, лента, стили)
- **Domain** — сервисы и бизнес-логика, доменные классы
- **Database** — таблицы, данные для расчетов. Файлы не зашиваются в проект, а кладутся рядом с dll в исходном виде
- **Resources** — внутренние ресурсы, иконки и т.д.
- **Commands** — верхнеуровневые команды, связь с Revit. Вызывает сервисы и окна. 

---

## Правила размещения файлов

### UI
Сюда кладутся все файлы, связанные с пользовательским интерфейсом:
- `Windows/` — окна WPF (.xaml, .xaml.cs) и их ViewModel
- `Controls/` — пользовательские элементы управления

### Domain
Сюда кладутся классы бизнес-логики:
- `Services/` — сервисы, выполняющие основную работу
- `Classes/` — доменные модели, DTO, вспомогательные классы
- `Commands/` — команды для MVVM (RelayCommand и др.)

### Database
Сюда кладутся данные для расчетов и таблицы:
- JSON, XML, CSV файлы с данными
- Файлы конфигурации, которые должны быть доступны для редактирования рядом с dll
- **Важно:** эти файлы могут копироваться в выходную директорию 

### Resources
Сюда кладутся внутренние ресурсы проекта:
- Иконки (.png, .ico, .svg)
- Изображения
- Встроенные ресурсы (Build Action: Embedded Resource)
- **Важно:** эти файлы никогда не копируются в выходную директорию и являются встроенными ресурсами

### Commands
Сюда кладутся классы для запуска в контексте Revit:
- Классы, реализующие `IExternalCommand` (команды, вызываемые из ленты).
 
---

## Ключевые паттерны

- **MVVM:** используется для UI (`UI/` папка) — ViewModel + View + RelayCommand
- **Внедрение зависимостей:** модели передаются в сервисы через SimpleInjector
- **Слой сервисов:** бизнес-логика изолирована в `Domain/Services/`
- **Интеграция с Revit:** интерфейсы `IExternalCommand` в `Commands/`
- **Разделение данных:** исходные данные в `Database/`, встроенные ресурсы в `Resources/`
